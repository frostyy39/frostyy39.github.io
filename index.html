Frosty Performance Sync

Frosty Performance Sync is a personal recovery tracker for one account owner. With the owner’s permission, it uses the Google Health API to read daily resting heart rate, heart rate variability and completed-day calorie totals. It checks each measurement’s date and source before writing verified values to the owner’s private Google Sheet.

The Google Health integration handles numeric fitness measurements for personal training and recovery. It does not access images or videos or use Google Health data to generate media.
